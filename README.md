# Rock Paper Scissors Game in Python 🎮

This is a simple command-line based **Rock, Paper, Scissors** game written in Python.  
The user plays against the computer, which makes random choices each round.

---

## 🧠 How It Works

- The user is prompted to enter a choice: **rock**, **paper**, or **scissors**
- The computer randomly selects one of the three
- The winner is determined based on classic rules:
  - Rock beats Scissors
  - Paper beats Rock
  - Scissors beats Paper
- The user is asked whether they want to play again after each round

---

## 📦 Features

- ✅ Validates user input
- ✅ Randomized computer moves
- ✅ Keeps prompting until user chooses to quit
- ✅ Clear game result messages

---

## 🛠️ Tech Stack

- Language: **Python 3**
- Library: `random`
